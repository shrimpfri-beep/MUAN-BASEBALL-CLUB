# 무안BC야구단 창단 10주년 기념행사 초대장

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `muanbc-10th`, Public)
2. 이 폴더의 파일 전체(`index.html`, `images/`, `video/`)를 업로드
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 후 `https://<아이디>.github.io/muanbc-10th/` 접속

## 카톡 공유 미리보기
`index.html` 상단의 `og:image`, `og:url` 두 줄에서 `YOUR-ID`를 본인 GitHub 아이디로 바꾸세요.
(카톡은 미리보기를 캐시하므로, 수정 후엔 https://developers.kakao.com/tool/debugger/sharing 에서 캐시 초기화)

## 사진 추가·변경
`images/` 폴더에 사진을 넣고 `index.html` 하단 `PHOTOS` 목록에 `['파일명.jpg','설명']` 한 줄 추가.
